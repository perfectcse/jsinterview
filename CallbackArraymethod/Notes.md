1. Complete Array Methods Comparison

| Method      | Main Purpose                         | Returns                    |
| ----------- | ------------------------------------ | -------------------------- |
| `forEach()` | Perform an action for every element  | `undefined`                |
| `map()`     | Transform every element              | New array                  |
| `filter()`  | Select elements matching a condition | New array                  |
| `find()`    | Find the first matching element      | Single value / `undefined` |
| `some()`    | Check whether at least one matches   | `true` / `false`           |
| `every()`   | Check whether all match              | `true` / `false`           |
| `reduce()`  | Build one final result               | Any accumulated value      |


forEach → DO
map     → TRANSFORM
filter  → SELECT ALL
find    → FIND FIRST
some    → AT LEAST ONE?
every   → ALL?
reduce  → COMBINE
